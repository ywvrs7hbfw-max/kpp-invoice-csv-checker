# Invoice CSV Checker

A small, browser-local CSV checking tool. Open `index.html` in a current browser and use the on-page instructions and example data. Files stay in the browser. It checks the stated input format; it does not determine tax treatment or perform bookkeeping.

## Installation
Download this repository and open `index.html`, or serve it as a static page. No package installation, server database or third-party analytics is required.
